GURU CONNECT — ADVERTISEMENT SYSTEM

1) Run SUPABASE_ADVERTISEMENTS_SETUP.sql once in Supabase SQL Editor.
2) Log in as Staff/Admin.
3) Open Admin Dashboard > ADVERTISEMENTS.
4) Upload JPG/PNG/WEBP flyer (maximum 3 MB).
5) Choose placement:
   - Post Ad in LRR
   - Post Ad in Student Profile Section
   - Post Ad in Tutor Profile Section
   - Post Ad in All Sections
6) Optional: set advertiser website / WhatsApp link, start date, end date and priority.

RECOMMENDED CREATIVE SIZES
- Student/Tutor Profile card: 1200 x 800 px (3:2 landscape)
- LRR card: 1000 x 1200 px (5:6 portrait)
- Accepted upload formats: JPG, JPEG, PNG, WEBP
- Maximum upload size: 3 MB

The website automatically fits the flyer to the existing card footprint. Advertisements are read from Supabase and can be activated/paused/deleted from the Admin Dashboard.
